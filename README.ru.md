# Как играть в Beat Saber на Quest 3 и показывать игру на телевизоре Samsung с Tizen

[العربية](README.ar.md) · [中文](README.zh.md) · [English](README.md) · [Français](README.fr.md) · [Русский](README.ru.md) · [Español](README.es.md)

**Один игрок, два экрана.** Beat Saber запускается на ПК с Windows. Virtual Desktop передаёт VR-игру в Quest 3, а Sunshine одновременно захватывает рабочий стол ПК и передаёт его по домашней сети в Moonlight на Samsung BU8000. Зрители видят то, что показано на мониторе компьютера.

**Что понадобится.** Игровой ПК с Windows и ПК-версией Beat Saber, Quest 3 с уже настроенным Virtual Desktop для PCVR и Samsung BU8000 в той же домашней сети. В проверенной конфигурации на телевизоре стояла Tizen 6.5, игровой ПК был подключён по Ethernet. Приложение на телевизор устанавливали с отдельного компьютера под Windows.

## Однократная настройка

1. **На игровом ПК** установите [Sunshine для Windows](https://github.com/SunshineStream/Sunshine/releases/latest). На этом же ПК откройте [локальную панель Sunshine](https://localhost:47990), задайте логин и пароль. Оставьте **Desktop** в списке приложений.
2. **На телевизоре** откройте **Apps** и наберите **12345** для входа в меню разработчика. Включите **Developer Mode**. В поле **Host PC IP** укажите локальный IP компьютера, с которого будете устанавливать Moonlight. Если меняли настройку, перезапустите телевизор. В проверенной конфигурации в этом поле был адрес отдельного компьютера для установки. [Инструкция Moonlight для Tizen](https://github.com/brightcraft/moonlight-tizen/wiki/Installation-Guide)
3. **На компьютере для установки** скачайте обычный **Moonlight.wgt** со [страницы релизов Moonlight Tizen](https://github.com/brightcraft/moonlight-tizen/releases). Установите этот файл на телевизор через **Apps2Samsung**. В нашем случае установщик использовал существующий сертификат Samsung Partner для этого ТВ. При первой установке следуйте подсказкам по созданию сертификата. [Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung)
4. **На телевизоре** откройте Moonlight и выберите игровой ПК. Если его нет в списке, добавьте вручную локальный IP его Ethernet-подключения. На экране появится PIN. В панели Sunshine на игровом ПК откройте **PIN**, выберите запрос телевизора и введите этот код.

Если используете Apps2Samsung CLI для Windows, откройте PowerShell в папке с утилитой и пакетом. Замените `TV_IP` адресом телевизора, а `INSTALL_PC_IP` — адресом компьютера, с которого устанавливаете пакет.

```powershell
.\apps2samsung-cli.exe install .\Moonlight.wgt --tv TV_IP --local-ip INSTALL_PC_IP
```

## Как запустить игру для зрителей

Запустите ПК-версию Beat Saber через Virtual Desktop в Quest 3. Посмотрите на монитор ПК и убедитесь, что на нём видна игра в том виде, который хотите показать зрителям. На телевизоре откройте **Moonlight → игровой ПК → Desktop**. Если на ТВ виден рабочий стол Windows, сначала проверьте, что открыто на мониторе, который захватывает Sunshine.

**Что проверено.** Игрок подтвердил запуск Beat Saber. Sunshine зарегистрировал сопряжение BU8000 и начало сеанса с аппаратным кодированием H.264 на RTX 3070, запросом 60 кадров/с и захватом стереозвука. Какое именно окно показывало игру, не зафиксировали. Сквозную задержку не измеряли.
